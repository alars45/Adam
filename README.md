# 🐶✨ Paws-Man ✨

Pac-Man, but Pac-Man is an extremely flamboyant dog in a pink polka-dot bandana.

Open `index.html` in any modern browser. No build step, no dependencies.

## How to play
- **Arrow keys / WASD** (or swipe on mobile) to strut through the maze
- **Enter / Space / tap** to start
- **P** to pause, **M** to mute

## The cast
- **Paws-Man**: golden pup with glittery eyeshadow, dramatic lashes, a bow on the ear, a pink bandana, and a rainbow sparkle trail
- **The cats** (instead of ghosts): Mr. Hiss, Duchess, Tomcat and Grumpus, who chase like the classic ghosts (Blinky, Pinky, Inky and Clyde)
- **Kibble** (10 pts), **disco balls** (50 pts, power-up: the cats get scared), **bone treats** (bonus fruit)

Expect sass: *FABULOUS!*, *SLAY!*, *BYE, KITTY!*, *NOT THE BANDANA!*
